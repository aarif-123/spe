# Voice Notes

A browser-based speech-to-text page. Open `index.html` in a supported browser, allow microphone access, and select **Start listening**. Speech recognition requires a compatible browser (such as Chrome or Edge) and an internet connection.

## Deploy to Vercel

This is a static site and needs no build step or dependencies. Import this repository into Vercel and use:

- Framework preset: **Other**
- Build command: leave blank
- Output directory: `.`

Vercel will serve `index.html` from the project root.
